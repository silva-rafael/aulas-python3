# Funções em python

## O que é uma função?
Uma função é um bloco de código que só é executado quando é chamado.
Uma função pode retornar dados como resultado.
Uma função ajuda a evitar repetição de código.

## Como declarar uma função em python?
Em Python, uma função é definida usando a def palavra-chave `function`, seguida pelo nome da função e parênteses:

``` python
def somar():
    print(2 + 3)
